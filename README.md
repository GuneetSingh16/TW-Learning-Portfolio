# TW Learning Portfolio

**Technical Writing (TW) — Learning Documentation**

This repository is my learning portfolio for the Technical Writing course. It contains explanations, syntax references, practical examples, and command practice for the tools covered in class.

## Topics covered

1. **LaTeX** — document structure, formatting, equations, tables, figures, references, and bibliography.
2. **Beamer** — creating presentation slides using LaTeX.
3. **Doxygen** — generating software documentation from source-code comments.
4. **Google Docs** — document formatting, collaboration, comments, sharing, and version history.
5. **Git and GitHub** — version control, repositories, commits, branches, remotes, and collaboration.

## How to use this repository

- Open each topic folder and read its `README.md`.
- Check the `Examples` folder for practical files.
- Try the commands in `05-Git-GitHub/GIT-COMMAND-PRACTICE.md` in your own test repository.
- Add your own screenshots, class exercises, and reflections as you learn.
