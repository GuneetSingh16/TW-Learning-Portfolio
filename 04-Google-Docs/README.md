# 04 — Google Docs

## What is Google Docs?

Google Docs is an online word processor that allows users to create, edit, format, and share documents through a web browser. Documents can be stored online and edited collaboratively.

## Main features

- **Document formatting:** headings, fonts, alignment, spacing, and page setup.
- **Collaboration:** multiple people can work on the same document.
- **Comments:** users can leave feedback without changing the main text.
- **Suggesting mode:** proposed edits can be reviewed and accepted or rejected.
- **Version history:** earlier versions can be viewed and restored.
- **Sharing permissions:** access can be set to Viewer, Commenter, or Editor.

## Creating a document

1. Open Google Docs.
2. Create a blank document or choose a template.
3. Add a title and organise content using heading styles.
4. Insert tables, images, links, or page numbers if required.
5. Rename the document.

## Collaboration and sharing

Use the **Share** option to invite collaborators. Give each person only the access they need:

| Role | Permission |
|---|---|
| Viewer | Can view the document |
| Commenter | Can view and add comments |
| Editor | Can make changes |

## Version history

Open **File → Version history → See version history** to inspect earlier edits. You can identify changes and restore an earlier version when necessary.

## Good document practices

- Use heading styles consistently.
- Keep paragraphs clear and concise.
- Use meaningful file names.
- Check spelling and grammar.
- Confirm sharing permissions before sending a link.

## What I learned

Google Docs supports cloud-based document creation and real-time collaboration. Comments, suggesting mode, and version history help teams review work effectively.

## Practical task

Create a one-page report, apply heading styles, add a table, share it with a classmate as a commenter, and add a comment.
