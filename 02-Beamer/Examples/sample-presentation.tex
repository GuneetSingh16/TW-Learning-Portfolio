\begin{frame}{What is Beamer?}
    Beamer is a LaTeX document class used to create presentations.
    \begin{itemize}
        \item Slides are written as frames.
        \item Themes control slide appearance.
        \item Equations and lists are supported.
    \end{itemize}
\end{frame}

\begin{frame}{A Mathematical Example}
    The quadratic formula is:
    \[
    x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}
    \]
\end{frame}

\begin{frame}{Conclusion}
    Beamer makes it possible to create structured presentations using LaTeX.
